# habit_focus

Habit tracker with a focus mode. Production-style Flutter app built end to end:
Clean Architecture, BLoC, offline-first sync with a Symfony backend, flavors,
secure token handling, native bridges (haptics, sensors), automated tests and CI.

> Work in progress. See `AGENTS.md` for engineering rules, `docs/` for UI and
> testing guidelines and `SETUP.md` for first-time setup.

## Stack

Flutter (pinned with FVM), `material_ui` (Material 3), `flutter_bloc`,
`go_router`, `dio`, `flutter_secure_storage`, `drift`, `get_it`.
Android and iOS; releases are distributed as APKs via GitHub Releases.
